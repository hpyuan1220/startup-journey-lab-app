# Startup Journey Class

Use the current repository and teacher handbook as the source of truth. Read existing materials before editing, preserve completed work, and use Traditional Chinese for user communication and student-facing content.

## Stable course rules

- Audience: 50 Taiwan university students who are not native English speakers.
- Duration: 120 minutes per week.
- Teams: up to three students.
- Weeks 1–4: every student keeps an individual pain-point map, observations, interviews, evidence, and decisions.
- Week 5: each team selects one topic from member evidence and defines one testable MVP.
- Weeks 6–10: the team proceeds together while each member records contribution and reflection.
- Use YC Startup School videos as teaching inputs. Convert each video into three to five teachable judgments tied to an activity and submission.
- AI may assist research, organization, prototyping, translation, and anonymous analysis. AI output is not user evidence. Students retain sources, key prompts, checks, and final responsibility.

Read [references/course-framework.md](references/course-framework.md) before designing or revising a week.

## Workflow

1. Read the repository README, course blueprint, project state, current week materials, previous week materials, and web app.
2. Identify what already exists and what must change. Do not create a duplicate site or parallel course version.
3. Define one core weekly submission and the evidence students need to produce.
4. Draft the 120-minute lesson plan before creating presentation slides or web fields.
5. Create or update:
   - teacher lesson plan;
   - professional PPTX;
   - PDF reading version with identical slide content;
   - student worksheet;
   - weekly web page and data fields;
   - teacher insight requirements.
6. Use a concrete student example and a common-error example. Keep facts, assumptions, opinions, and decisions distinct.
7. Test the student flow, teacher flow, persistence, submission, mobile layout, and JavaScript console.
8. Update the course state and decision record. Preserve Git commits at stable stages when working in a repository.
9. Report completed flow, files, tests, commit, published URL, and deferred scope.

## Content quality

The weekly objective, classroom activities, worksheet fields, web fields, submission, and grading language must match. Keep the interface simple and keyboard accessible. Explain essential startup English terms in Chinese. Do not claim old video content is current practice; add current context when needed.

For a new topic that differs from the existing ten-week map, preserve the same evidence path: observation or prior evidence, concept, guided practice, student production, peer check, submission, and next-step connection. Record any change that affects later weeks before modifying downstream materials.
