# 好痛點的 8 個標準（Startup Journey Lab · Week 2→Week 3）

一個「可以帶到期中之後繼續做」的痛點，要能同時回答下面 8 題。每題 0／1／2 分，滿分 16。

| # | 標準 | 2 分 | 0 分 |
|---|---|---|---|
| 1 | **具體的人** | 說得出是哪一群人、在哪裡找得到（「午休只有一小時的大二生」） | 「我」「所有人」「大家」 |
| 2 | **可觀察的情境** | 有時間、地點、正在做什麼（「週三 12:00 校園餐廳窗口前」） | 「平常」「生活中」 |
| 3 | **阻礙＋代價** | 卡在哪一步、損失多少（「排 20 分鐘，常放棄午餐」） | 只有形容詞（「很麻煩」） |
| 4 | **重複發生** | 每週一次以上 | 一學期一次、出國才會 |
| 5 | **親眼證據** | 最近一次真實事件，有日期有細節 | 「我猜」「應該很多人」 |
| 6 | **現有做法不夠** | 他們已經在用某個笨方法，而且會抱怨它 | 沒人在處理（可能根本不痛） |
| 7 | **是問題不是解法** | 描述困擾本身 | 把「App」「AI 一鍵」「蓋一個場所」寫進問題裡 |
| 8 | **一週內訪得到 3 個人** | 已列出具體對象與時機 | 受訪者欄空白或是「我的隊友 ×3」 |

**判定**
- **A 可直接用**：≥12 分，且 #1、#3、#5 都不是 0
- **B 改一改就好**：8–11 分，或 ≥12 但 #7 是 0（把解法拿掉就好）
- **C 建議換題或併入別組**：≤7 分，或痛點只存在於學生本人（純個人習慣／偏好）

**老師審核時的三個快速提問**（對應 #1、#3、#5）
1. 這是誰的痛？我下週能在校園裡找到 3 個這樣的人嗎？
2. 上次發生時，他損失了什麼？說得出數字嗎？
3. 這是你親眼看到的，還是你猜的？
