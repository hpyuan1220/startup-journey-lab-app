# 提示詞包（老師複製貼給自己的 AI 助理用）

每一段都是「貼上去就能用」的指令。用《 》標的地方換成你的東西。順序照著做。

---

## P0　開場（每個新對話的第一句）

```
你現在協助我把「教學互動平台」改成我的課。先讀 docs/HANDOFF.md、docs/ADAPTATION_GUIDE.md，再讀我附上的《開課工作單 v2》。
規則：我按 push／Run／Deploy，你準備與驗證；不用真實學生資料；學生姓名學號只放 docs/private/；一次只改一件事，改完跑測試；每次回報分「實證／推論」。
讀完先告訴我：你理解我的課每週要學生交什麼、第一個要做的里程碑是哪一週的哪一張卡、你還缺哪些資訊。不要開始改程式。
```

## P1　從簡報反推學習卡（老師只有簡報和影片、還沒想好卡片時）

```
這是我第《N》週的簡報《檔名》和影片《連結》。請讀完之後回答：
1. 這週學生學完能「做」什麼（不是「知道」什麼）？用一句話。
2. 如果要學生交一張卡，3–6 格，每格的名稱請用學生看得懂的話，每格給一個真實例子。
3. 哪幾格是必填？提交前要擋什麼？
4. 這張卡是「有真實產出」（學生要去觀察、問人、做東西）還是「只是反思」？老實標。
用表格給我，我會打勾或改字，不要直接改程式。
```

## P2　產生「做得好」的標準

```
針對《第 N 週的卡片名稱》，依照 01_教學理念/設計原則.md 第 7 條「證據勝過意見」，列 4–8 條標準。
每條要有：標準名稱、2 分長什麼樣、0 分長什麼樣、學生缺這一項時可以直接點選的句型（像「____（身分）的____（情境）」）。
達標線：建議「至少幾條 ≥1 分、總分 ≥ 多少」。
標準打分的是證據不是文筆。給我表格，先不要改程式。
```

## P3　建第一張卡（確認 P1、P2 之後）

```
照 docs/ADAPTATION_GUIDE.md 第 2 節，把第《N》週的卡做出來。選《Week 1／Week 2／Week 3》當底。
先列出你要改的檔案清單和每個檔案改什麼，等我說「開始」再動。
做完之後：跑 node --test tests/*.test.mjs，新增這張卡的單元測試和一條真瀏覽器端到端測試，給我測試結果與一張手機寬度的截圖。
```

## P4　AI 建議（只有要 AI 才用）

```
照 docs/ADAPTATION_GUIDE.md 2.4 幫這張卡接 AI 建議。
AI 可以看的格子：《列出》。絕對不能送的：《列出》。
AI 的角色是《只提問／給三個方向／指出缺口》，口吻像《例：學長姊》，不打分、不代寫。
system prompt 裡「不可信資料」「不評成績」「不輸出姓名學號」「不代寫」四句不能刪。promptVersion 換新字串。
做完給我：你送給 AI 的實際內容一份範例（用測試資料），證明裡面沒有姓名學號。
```

## P5　上線

```
照 04_開班與營運/上線流程.md 帶我上線。每一步先告訴我你準備好了什麼、我要按哪一顆、按完你會怎麼驗證。
部署前要給我三方雜湊比對的結果；部署後要做零寫入探針並用我的測試學號唯讀載入。
```

## P6　開班

```
照 04_開班與營運/開新班手冊.md 幫我開班。班級名稱《》、邀請碼《》、名單在 docs/private/《檔名》。
先產生只建班的第一段 SQL，我跑完把 class_id 給你，再產生第二段。跑完用不在名單的學號做探針，確認被擋。
```

## P7　每週例行（開學後）

```
現在是第《N》週上課前。請：
1. 看教師洞察的進度（用我的教師帳號，我已登入），告訴我幾人交了、幾人沒開始、哪些要我先看。
2. 如果這週要加新的卡或教材，照 ADAPTATION_GUIDE 2.1 做學習頁，照 2.2 做卡。
3. 上課當天我要做的事列成三段：課前、課中、課後，每段不超過五條。
```

## P8　出事的時候

```
學生反映《症狀》。不要先改程式。先：
1. 用我的測試學號重現，告訴我你看到什麼（截圖或畫面文字）。
2. 查後端錯誤（Supabase logs）與瀏覽器 console。
3. 判斷是資料、畫面、還是流程問題，告訴我資料有沒有遺失。
4. 給我最小修法和風險，等我說「做」。
```

---

## 給老師的三個提醒

- AI 助理說「應該可以」時，問它「測試跑了嗎、結果呢」。
- 它要你貼密碼或金鑰到對話裡時，不要。金鑰放 Supabase 的 Secrets，密碼你自己輸入。
- 每次上線之後，自己用測試學號走一遍學生會走的路。這十分鐘比任何測試都值。

## P9　影片中文導讀：分段意譯＋本課應用，放進學習頁與簡報

```
第《N》週的影片是《影片名稱＋YouTube 連結》。請：
1. 用 WebSearch／WebFetch 找這支影片的章節與時間戳（不要憑記憶），列出所有重點——不限五個，有幾個算幾個。
2. 寫 docs/WEEK<N>_YC_GUIDE.md：每個重點一節，格式照 docs/WEEK3_YC_GUIDE.md——「重點 N（時間戳）：標題」，底下四條：YC 影片觀念（意譯）、中文解釋、學生例子（本課）、《這週的卡》應用。開頭加一段「怎麼開自動翻譯字幕」。
3. 學習頁：把每個重點做成 week.html 該週 #week-<n>-materials 裡的 .yc-guide 區塊（一個重點一個可展開的 details，標題帶時間戳），放在影片連結下面、120 分鐘流程上面。
4. 簡報：docs/WEEK<N>_SLIDES_SOURCE.json 用新式格式（header + slides[{template, texts}]），每個重點一頁、用範本第 9 頁的四格版面（template: 9），放在「本週 YC 影片」那頁之後；「影片的 N 個提醒」那頁改成「前五個」並註明其餘在第幾頁。然後 python3 scripts/build-slides.py --source … --out …，soffice 轉 PDF，做接觸表目視檢查溢出，太長就縮短文字。
5. 回報：重點數、學習頁截圖、簡報新頁截圖；標明實證／推論。
```
