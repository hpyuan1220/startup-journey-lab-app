## 開場

大家好，這支影片用十分鐘，把 11/20 專題講座三小時的主軸先講一遍。上課答課堂題的時候可以回來重聽，缺課的同學也可以用它補。

先問兩個問題。第一，你有沒有用 ChatGPT 或 Gemini 寫過作業、翻譯過東西？應該幾乎每個人都有。第二，你有沒有讓 AI 自己幫你訂餐廳、自己讀信箱回信、自己把發票整理成 Excel？應該很少。

這個落差就是這堂課的主題：會聊天，不等於會做事。

## 第一段：Chatbot 和 Agent 差在哪

**在講什麼。** 講座用廚房的鍋具來比喻三代工具。

第一代是傳統軟體，像鐵鍋加瓦斯爐。Excel、ERP 都很好用，但是買菜、切菜、開火、翻炒，全部要你自己來。

第二代是第一代 AI，也就是早期的聊天機器人，叫做「語音食譜機」。你問它紅燒肉怎麼做，它一秒就唸出完美的步驟。可是菜還是你切，火還是你顧。它只出嘴，不出手。

第三代是 AI Agent，叫做「全自動料理機，加上自動買菜車」。你只要說一句「今晚八點吃低脂紅燒肉」，它自己查冰箱、自己下單買肉、自己控溫燉煮，時間到把菜端上桌。

**一個例子。** Agent 為什麼做得到？因為它有四個動作在循環。第一是感知：冰箱裡有什麼、時間還剩多少。第二是推理和拆解：缺肉就先下單，燉煮要九十分鐘，所以六點半要開火。第三是呼叫工具：打開購物 App、控制電鍋、查行事曆。第四是自己完成、自己修正：太鹹就加水重煮，缺貨就換一家買。聊天機器人只有第二個動作，Agent 四個都有。

**再一個例子：課堂上的現場示範。** 講座當天會現場示範兩個任務。第一個是跨工具：讓 AI 接上行事曆和信箱，跟它說「查下週三下午有沒有空檔，有的話找大安區評分四點五以上的商業午餐，並寫一封邀約信草稿」。第二個是多步驟資料處理：拍一張亂七八糟的紙本發票，請它辨識金額與品項、照會計科目分類、匯出 Excel，並檢查總額。示範的時候請注意畫面上出現的「正在呼叫工具」這幾個字，那就是 Agent 伸出手腳的瞬間。2026 年的 Agent 還能直接看螢幕、點滑鼠，去操作沒有提供連接方式的舊系統。

用企管的話講：以前的 AI 是軍師，給你建議，你自己去執行。現在的 Agent 是實習生或外包商，你給目標，它自己找工具把事做完。管軍師靠問對問題；管實習生靠拆流程、給工具、設關卡。

**對你這週的意義。** 請記住「語音食譜機」和「全自動料理機」這兩個暗號，整堂課都會用，課堂題也會用。現在就可以先想：你平常用的 AI，是哪一台？

## 第二段：方向一，Agent 經濟的基礎設施

**在講什麼。** 接下來講三個做生意的方向。方向一是基礎設施，一句話叫「淘金熱裡賣鏟子」。1849 年的淘金熱，真正賺到錢的是賣牛仔褲和鏟子的人。方向一的公司不做面對消費者的 AI，它做的是讓 Agent 能運作、能被信任、能收付錢的底層系統。它的客戶是做 Agent 的公司，不是一般企業。

**一個例子。** 想像你聘了一位超聰明、但偶爾會喝醉的實習生，喝醉就是 AI 的幻覺。你敢直接把公司信用卡交給他嗎？不敢。所以你需要五樣東西：一個萬用插座，讓它插上就能連進 LINE、ERP、資料庫；一套記憶，記得客人上次嫌太鹹；一張門禁卡，規定它只能看不能改，超過一千元要主管按確認；一支食安探針，二十四小時盯著它有沒有亂講話；還有一張限額信用卡，讓它能付錢、能結算。這五樣就是方向一在賣的東西。

**企管系可以做的四種生意。** 第一種，產業專用插座：幫你熟的產業，像診所、會計事務所、餐飲 POS、補習班，做好連接器，賣給做 Agent 的公司，收每月授權費或按呼叫次數收費。第二種，Agent 的門禁與簽核：設定每隻 Agent 能看什麼、能改什麼、多少錢要誰簽，接進 LINE 或 Teams，收導入費加每月維運費。第三種，Agent 的稽核與簽證：像會計師查帳一樣，定期抽測 Agent 會不會做錯、出具報告，賣給董事會、保險公司和法遵部門。第四種，Agent 之間的結算與爭議處理：A 公司的 Agent 跟 B 公司的 Agent 交易之後，誰對帳、誰退款？做中間的平台，每筆抽小額手續費。

**對你這週的意義。** 賣鏟子不一定要會做鏟子，需要的是懂產業流程、懂內控、懂合約的人，這正是企管系的強項。辨認方式只有一個：它的客戶是不是「做 Agent 的公司」。

## 第三段：方向二，AI 原生服務

**在講什麼。** 方向二是直接賣做完的結果。傳統軟體公司賣你一口頂級不沾鍋：賣會計軟體、客服系統，按員工帳號數收月租。鍋買回來，你還是要花薪水請人來炒。方向二的公司直接送來一桌煮好的外燴。客戶要的是帳記完、客服接完、文件審完。這種公司外表像事務所、像客服中心，裡面其實是一隊 AI Agent，人只做最後的抽查。收費是按件、按結果，不按帳號數。

**一個例子。** 算一題給你看。一家小公司每個月記帳，買會計軟體大概三千元，這是軟體預算；請記帳會計或外包大概三萬五千元，這是人力預算。現在來了一家方向二的公司，說「一個月一萬五，我把整本帳做完」。老闆省了一半以上的人力成本，而這家 AI 公司的營收，是賣軟體的五倍。

所以方向二的關鍵句是：它搶的是人力預算，不是軟體預算。

但是有一個代價。賣工具可以錯，因為使用的人自己負責；賣結果不能錯，因為是你要負責。所以這種公司一定有自我檢查的機制，像報表的借貸兜不攏，就退回上一步重算，只把對的東西交給老闆。

**它裡面怎麼分工：廚房流水線。** 方向二的公司不是讓一隻 AI 從頭做到尾，而是分工合作，這是企管系很熟的概念。以審合約為例：切菜 AI 負責讀完五十頁合約；炒菜 AI 負責比對公司法規、挑毛病；試吃品管 AI 負責寫修改建議；最後法務主管只看標紅字的地方。每隻 AI 專精一件事，所以更穩、更好監控、也更便宜。也因為會自我修正，任務可以放著跑好幾個小時，或是按排程自動執行。

**企管系可以做的四種生意。** 做法都一樣：找一筆老闆每個月固定要付的人力預算，直接把結果賣給他。第一，中小企業的記帳與報稅做完：收發票照片和銀行明細，Agent 分類、對帳、出報表，會計師最後簽核。第二，電商客服與退換貨接完：從回私訊、尺寸建議、退貨審核到退款一條龍，人只處理爭議件，每處理完一件收固定費。第三，政府補助與標案文件寫完：讀公告、比對資格、寫申請書，顧問只改最後一版，收基本費加核准後抽成。第四，招募初篩與排面試做完：讀履歷、初篩、約面試、寄通知，賣給常態缺工的餐飲、物流和製造業。

**對你這週的意義。** 看你自己的產業線：老闆每個月固定在付哪一筆人力的錢？那一筆，就是方向二的機會。課堂上會請你說，你的產業線搶的是老闆哪一筆預算。

## 第四段：方向三，AI 進入實體世界

**在講什麼。** 前兩個方向的 AI 都活在螢幕裡。方向三不一樣：它的輸入來自感測器和鏡頭，像照片、聲音、溫度、位置；它的輸出是對實體世界的動作，或是現場人員的調度。

**一個例子。** 半夜，你的車在路邊拋錨。你把儀表板警示燈拍一張照片，再錄一段發不動的引擎聲，傳出去。AI 十秒內判斷：是電瓶沒電，不是引擎故障，帶跨接電源去就好，大約二十分鐘，不用派拖吊車。接著它找出離你最近、車上有設備、現在有空的技師，把救援單、導航和處理步驟推到他的手機上。

請記住這三步：感測輸入、AI 判斷、實體調度。還有一個重點：如果判斷錯的代價很高，例如看起來像是事故，還是要轉給真人客服確認。這叫「人在迴路裡」。

方向三其實有兩種能力。剛才的道路救援是第二種，有人在迴路裡。第一種是硬體自己動作，整條鏈沒有人：工廠產線的鏡頭一秒抓出瑕疵品，機械手臂直接挑掉；農場的無人機看出哪幾棵果樹缺水或長蟲，只對那幾棵噴灑；物流倉庫裡幾百台搬運機器人自己規劃路線、彼此讓路；零售門市的貨架鏡頭發現缺貨或擺錯，自動下補貨單。至於人形機器人，現在還在試點期，卡在四個瓶頸：手、電池、安全標準，還有真實場景的資料。

醫院和長照也是同一個道理。鏡頭判斷長輩半夜有沒有跌倒的風險，第一時間呼叫離病房最近的照護員。AI 沒有取代照護員，它取代的是排班、盯監視器、打電話找人這些調度的工作。我們這門課研究這類題目，只做提醒、排班、派工這一層，不做診斷。

**企管系可以做的四種生意。** 都是不造機器人，只做「讓感測器變成派工」的那一層。第一，水電冷氣維修派工：客人拍照加錄聲音，Agent 判斷故障和需要的零件，派最近、有料、有空的師傅，每趟抽成或收師傅月費。第二，長照與安養機構的跌倒與異常監測：判斷跌倒、夜間離床、太久沒活動，第一時間呼叫最近的照護員並留下紀錄，按床位每月收費。第三，餐飲後場視覺：鏡頭看冰箱和備料區剩多少、放多久、溫度對不對，自動叫貨並留食安紀錄。第四，農業巡田與精準噴灑：無人機找出缺水和病蟲害的區塊，只處理那幾棵，按公頃按次收費。

**對你這週的意義。** 方向三對台灣學生特別近，因為鏡頭、感測晶片、機械手臂的供應鏈都在台灣。企管系不用去造機器人，機會在「讓感測器變成派工」的那一層流程設計。辨認方式：一定有硬體，或是有現場人員在迴路裡。

## 第五段：三家傳統企業怎麼改造

**在講什麼。** 最後一節是實戰演練：假設你是轉型顧問，面對三家傳統企業。最常見的錯誤答案是「導入 ChatGPT 當客服」。那只是多放一台語音食譜機。

分析任何一家公司，都問三個問題。第一，AI 的手腳是什麼：它接收什麼資料，會自己呼叫什麼工具、調度誰。第二，人類退到哪裡：哪些事不用做了，哪個高風險的環節還是要人按確認。第三，怎麼收錢、怎麼省錢。

**一個例子。** 三家各講一句。

連鎖火鍋店：食材常常叫太多放到壞，月底對發票很痛苦。做法是把銷售、進貨單、發票照片接起來，讓 AI 預測用量、自動開進貨單、月底自動對帳；超過門檻的進貨單，還是要店長按確認。這是方向一加方向二。

搬家公司：電話估價講不清楚，到了現場才發現車裝不下。做法是客人拍客廳和家具的照片，AI 估體積、選車型、算人數、報價，再照師傅的位置派車；鋼琴、保險箱這種特殊的，還是由調度員確認。這是方向三，跟剛才的道路救援是同一個結構。

電商服飾品牌：每天幾百則私訊問尺寸、問退換貨。做法是 AI 讀私訊、查訂單回覆，退貨進倉後拍照檢查，通過就自動退款；金額太高或疑似惡意退貨的，轉給真人。收費是每處理完一件退貨收十五元。原本兩位客服加一位倉管，一個月大約十萬；一個月三千件乘以十五元，是四萬五。這是方向二。

**老闆一定會問的四個問題。** 不管你提哪一個方案，老闆都會反問四件事。第一，它會不會做錯？會。AI 有幻覺、會誤判，步驟一多錯誤還會累積，所以才需要方向一的監控，和人工按確認。第二，它真的比較便宜嗎？不一定。Agent 每呼叫一次工具都要算錢，一個要跑兩百步的 Agent，可能比請工讀生還貴，所以要先算單件成本。第三，出事誰負責？AI 刷錯卡、派錯工，法律上還是公司負責，所以授權範圍要寫清楚，高風險的環節要留人簽核。第四，我們的資料準備好了嗎？大多數公司卡在這裡，資料散在 LINE、紙本和 Excel。研究機構 Gartner 預測，到 2027 年底之前，會有超過四成的 Agent 專案被取消。

**真的要做，先過四道篩選。** 第一，痛點夠不夠痛：老闆現在每個月為這件事付多少錢。第二，資料拿不拿得到。第三，做錯了能不能補救。第四，客戶願不願意按件付錢。拿三家來比：火鍋店的銷售資料有，但供應商的單據很多還是紙本；搬家的照片資料要從零開始累積，而且車派小了代價很高；電商的訂單、對話、照片都已經在系統裡，退錯款還追得回來，每件十五元也明顯比請人便宜。所以結論是：電商退貨的資料最齊、錯了最好補救，最適合當第一個題目。

**對你這週的意義。** 這三家對到班上人數最多的幾條產業線。上課的時候，請把這三個問題套到你自己組的產業線上。再用四個問題和四道篩選檢查一次：答得出來，才是老闆願意買單的方案。

## 收尾

三個方向，各用一句話辨認。方向一：淘金熱裡賣鏟子，客戶是做 Agent 的公司。方向二：搶的是人力預算，不是軟體預算，按件、按結果收費。方向三：一定有硬體，或是有現場人員在迴路裡。

再看一次時間軸。2023 到 2024 年，AI 會聊天，是語音食譜機。2025 年，AI 會用工具，伸出了手腳。2026 年，AI 能被交辦：可以跑好幾個小時、可以組隊、可以付錢。2027 年，AI 進到現場，同時開始被分級治理。知道哪裡交給 Agent、哪裡放感測器、哪裡留人把關，這就是企管人才的位置。
