Week 8 講義｜AI Agent 最新功能與三大商業趨勢

11/20 專題講座 ・ 從「買鍋子自己炒」到「全自動中央廚房」・ 講座內容由講師提供，本講義整理重點並接上本課的建組與 11/27 群島遊戲

一句話：以前的 AI 是軍師（給建議、你去做）；現在的 AI Agent 是實習生／外包商（你給目標、它自己找工具把事做完）。管理實習生靠的是：拆流程、給工具、設關卡——這就是組織設計。

1. 鍋具比喻：誰出嘴、誰出手？

傳統軟體＝鐵鍋＋瓦斯爐

Excel、ERP、SaaS 很好用，但買菜、切菜、開火、翻炒都要你自己來。

第一代 AI＝語音食譜機

你問紅燒肉怎麼做，它唸出完美步驟。菜還是你切——只出嘴、不出手。

AI Agent＝全自動料理機＋買菜車

你說「今晚八點吃低脂紅燒肉」，它自己查冰箱、下單、燉煮、端上桌。

Agent 的四個動作：①感知（冰箱有什麼）②推理拆解（缺肉先下單、6:30 開火）③呼叫工具（購物 App、電鍋、行事曆）④自主完成與修正（太鹹加水、缺貨換一家）。Chatbot 只有②。

2. 三個方向怎麼分（＝群島地圖的三大區）

方向一｜Agent 經濟基礎設施方向二｜AI 原生服務方向三｜走進實體世界
一句話淘金熱裡賣鏟子搶人力預算，不是軟體預算一定有硬體或現場人員在迴路裡
客戶是誰做 Agent 的公司一般企業的老闆有現場的企業：工廠、物流、零售、照護
賣什麼協定（MCP）、資料管線、授權、監控、結算做完的結果：帳記完、客服接完、文件審完派工、檢測、調度
怎麼收錢隨 Agent 數量成長（用量、授權）按件、按結果，不按席位設備＋服務，或按派工件數
資料從哪來別人的 Agent 透過你的插座客戶的文件、對話、帳務感測器與鏡頭
群島的島島 2 算力、島 3 資料平台、島 5 Agent 基礎設施島 4 AI 寫程式、島 6 垂直 Agent、島 7 消費創意島 8 實體 AI、島 9 世界模型、島 10 AI for Science

島 1 基礎模型（Mistral 等）是大家共用的「引擎」，在最底層。「三個方向」是目前創投圈常用的分類方式，不是單一出處。

3. 方向一的五大底層功能（你聘了一位偶爾會「喝醉」的實習生）

  1. 工具串接協定（萬用插座，如 MCP）：插上就能連進公司的 LINE、ERP、資料庫。
  2. 記憶與資料管線：記得客人上次嫌太鹹、對花生過敏；把亂七八糟的歷史資料洗乾淨。
  3. 身分與授權（門禁卡）：「只能看不能改」「超過 1,000 元要主管按確認」（Human-in-the-loop）。
  4. 評測與監控（食安探針）：24 小時盯著 AI 有沒有亂講話、偷工減料。
  5. Agent 之間的付款與結算（限額信用卡）：Visa、Mastercard、Google、Stripe 的標準陸續到位。

4. 企管系可以做的生意（講師列的 12 個題目）

方向題目：做什麼 → 賣給誰 → 怎麼收錢
方向一 ① 產業專用插座：幫你熟的產業（診所、會計事務所、餐飲 POS、補習班）做 MCP 連接器 → 做 Agent 的公司 → 每月授權或按呼叫次數
② Agent 門禁與簽核：設定每隻 Agent 能看、能改、多少錢要誰簽 → 不敢放權的中大型企業 → 導入費＋月維運費
③ Agent 稽核與簽證：像會計師查帳，抽測 Agent 會不會做錯 → 董事會、保險、法遵 → 按季／按年
④ Agent 結算與爭議處理：兩家公司的 Agent 交易後誰對帳、誰退款 → 供應鏈夥伴 → 每筆抽手續費
方向二 ⑤ 中小企業記帳報稅做完 → 沒有專職會計的小店 → 每月固定費，比外包便宜一半
⑥ 電商客服與退換貨接完 → 中小型電商品牌 → 每處理完一件收固定費
⑦ 政府補助與標案文件寫完 → 沒人力寫件的中小企業 → 基本費＋核准後抽成
⑧ 招募初篩與排面試做完 → 常態缺工的餐飲、物流、製造業 → 按職缺或到職人數
方向三 ⑨ 水電冷氣維修派工：拍照錄音判斷故障、派最近有料有空的師傅 → 維修行、物業 → 每趟抽成
⑩ 長照與安養機構的跌倒與異常監測：第一時間呼叫最近的照護員、自動留紀錄 → 安養中心、醫院病房 → 按床位月費
⑪ 餐飲後場視覺：看冰箱與備料區剩多少、放多久、溫度，自動叫貨與食安紀錄 → 連鎖餐飲 → 每店月費＋硬體租賃
⑫ 農業巡田與精準噴灑：無人機找缺水、病蟲害區塊 → 果園、茶園、合作社 → 按公頃按次

本課研究照護類題目時，只做提醒、排班、派工這一層，不做診斷或醫療建議。

5. 算術題：為什麼創投瘋狂投資方向二（小公司記帳，每月）

買會計軟體：3,000 元

這是「軟體預算」。

請記帳或外包：35,000 元

這是「人力預算」。

AI 公司把帳做完：15,000 元

老闆省一半以上；AI 公司營收是賣軟體的 5 倍。

挑題訣竅：找重複、規則明確、錯了可以補救的工作，先算出「老闆現在每月付多少人力、你收多少、還剩多少毛利」。

6. 導入前，老闆一定會問的四個問題

它會不會做錯？

會：幻覺、誤判、多步驟錯誤累積。所以要監控，高風險步驟留人按確認。

它真的比較便宜嗎？

每呼叫一次工具都要錢，跑 200 步的 Agent 可能比工讀生貴：先算單件成本。

出事誰負責？

AI 刷錯卡、派錯工，法律上還是公司負責。授權範圍要寫清楚。

資料準備好了嗎？

多數公司卡在這：資料散在 LINE、紙本、Excel。

7. 分析任何情境的三個企管問題（＝三個方向）

① AI 的手腳是什麼？

它接收什麼資料（文字、照片、感測器）？會自己呼叫什麼工具、調度誰？

② 人類退居哪裡？

原本的人不用做什麼了？哪個高風險環節還要「人類按確認」？

③ 怎麼收錢／省錢？

賣插座（方向一）？按件包結果（方向二）？軟硬整合派工（方向三）？

情境用哪個方向AI 的手腳人留在哪裡怎麼收錢
A 連鎖火鍋店方向一＋二接 POS、進貨單、發票照片；預測用量、自動叫貨、自動對帳超過門檻的進貨單、異常發票由店長確認總部：資料插座每店月費；單店：把帳做完按月按件
B 搬家配送方向三照片估體積件數、選車型、報價、依位置路況派車鋼琴、保險箱、特殊路況由調度員確認每趟抽成，或依車隊規模月費
C 電商服飾方向二回私訊、查尺寸；退貨拍照檢查、呼叫金流退款超過金額門檻、疑似惡意退貨轉真人每件退貨 15 元（原本約 10 萬／月人力）

挑第一個題目的四道篩選：痛點夠痛嗎（老闆每月付多少）？資料拿得到嗎？錯了可以補救嗎？客戶願意按件付嗎？——講師的結論：電商退貨資料最齊、錯了最好補救，最適合當第一個題目。

9. 下課前：建組與認領方向

規則

  1. 三人一組（最少 2 人），自己找組員，在 app 的 Week 8 頁登記。
  2. 一組一個產業線：組員 Week 4 選的產業不同沒關係，挑一條大家最清楚、最做得下去的。
  3. 三個方向各認領一人：在同一個產業裡，每人從自己的方向找一個題目。
  4. 期中不受影響：11/13 期中是個人報告，用自己 Week 4 的產業寫。

怎麼挑「組的產業線」（符合越多越好做）

  1. 誰的 Week 4 證據最完整：三張卡做完、卡 2 有 NotebookLM 來源。
  2. 找得到對照公司嗎：島 6 有餐飲（Owner）、網拍（Gorgias）、旅宿（EliseAI）、零工（Skello）。找不到＝美國歐洲也還沒做好＝機會。

挑組裡沒人做過 Week 4 的產業也可以，但要從零開始研究，比較辛苦。

12. 回家三件事

  1. 讓 AI 真的幫你做一件事：接上行事曆或信箱，交辦一個多步驟任務，看它呼叫工具。
  2. 把打工的流程畫出來：標出哪一步交給 Agent、哪一步要人簽核——這是面試最好的作品。
  3. 算一筆帳：那個流程一個月花多少人力？改成按件收費，你會收多少？
