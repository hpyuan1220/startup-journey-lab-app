## 測試指令及範圍

`node --test tests/*.test.mjs`：26 pass，0 fail。`node --check`：app、week2、teacher-week2、teacher-ai-feedback 通過。`git diff --check` 通過。

新增測試直接執行 Edge handler，資料層由可控 adapter 替代，測模型錯誤不產生付費呼叫。測試不保證 SQL 權限、transaction、PostgreSQL upsert 行為；正式部署清單要求另外驗證。

## 已修正的檢查發現

1. 初稿 BEFORE INSERT 快照會和 upsert 衝突，改成 BEFORE UPDATE 編版號、AFTER INSERT/UPDATE 保存快照，待真實 DB 驗證。
2. AI 元資料原會讓學生版本增加，改由已存 AI 結果推導求助排序。
3. 舊教師卡直接拼接學生文字，加入 HTML escaping；AI 區改以班級＋學號對應，避免跨班同學號錯配。
4. 草稿保存期間繼續打字可能被當成已同步，加入輸入版本檢查，保留未同步文字。
5. PDF 轉檔字型缺漏，指定本機中文字型目錄後重新轉檔與比對。
6. 原生 AI 確認框使測試瀏覽器卡住，改為頁內預覽／確認／取消，待解除瀏覽器阻塞後驗證。
